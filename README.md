# yipingbenjaminl.github.io

Personal website and static tools, hosted on GitHub Pages.

## Overview

This repository contains a lightweight personal site with a few small, client-side tools and reference pages. The site is intentionally static and easy to deploy to GitHub Pages without a backend.

## Tools and Pages

- **Statement Splitter** — Split Capital One Venture X PDF statements by cardholder with true PDF redaction. Runs entirely client-side using MuPDF WASM.
- **Anesthesia Study Guide** — A mobile-friendly chapter index and review page covering Miller 10e + Barash 9e complete chapter key points. Includes a desktop table of contents, mobile slide-out contents drawer, and chapter expand/collapse controls.
- **[Anesthesia Exam Simulator](https://yipingbenjaminl.github.io/exam-sets.html)** — Choose between two 260-question practice exam sets, answer with instant feedback, and review rationales, textbook references, and domain/difficulty filters for every question.

## Notes

- Built with plain HTML, CSS, and JavaScript.
- Designed for GitHub Pages hosting.
- Most logic runs in-browser for privacy and simplicity.
